# Papa Muay Thai

Catálogo digital mobile-first para el restaurante Papa Muay Thai, basado en la estructura de WENDELO.

## Funciones

- Menú público por categorías
- Orden por precio
- Consulta de cada plato por WhatsApp
- Área privada `/admin`
- Productos editables con Supabase
- Carga de una o varias fotos

## Configuración

Copiá `.env.example` como `.env.local` y completá Supabase y el número de WhatsApp en formato internacional, sin `+` ni espacios.

## Fuente del menú

Los platos y precios iniciales fueron extraídos de `Speisekarte 20250811.pdf`. El precio de “Agua sin Gas” debe confirmarse porque figura como `0` en el documento.
